# Cedars Special Needs Consult Website

Official public website project for Cedars Special Needs Consult, a child-development and special-needs support organisation based in Ilorin, Kwara State, Nigeria.

## Repository purpose

This repository is dedicated to the public website. It is separate from the professional Neurodevelopmental Practice and Care Management Platform.

## Run the foundation locally

1. Install Node.js 20.9 or newer and pnpm.
2. Open a terminal in this project folder.
3. Run `pnpm install` once to install the project packages.
4. Run `pnpm dev` to start the preview.
5. Open `http://localhost:3000` in your browser.

Useful checks are `pnpm lint`, `pnpm typecheck`, and `pnpm build`.
